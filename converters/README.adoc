# `acdc` converters

- `link:./html[html]` - `AsciiDoc` html backend
- `link:./manpage[manpage]` - `AsciiDoc` manpage backend
- `link:./markdown[markdown]` - `AsciiDoc` markdown backend (CommonMark & GitHub Flavored Markdown)
- `link:./terminal[terminal]` - `AsciiDoc` terminal printer backend (à la *nix command `cat`)

== Development prerequisites

Converter tests are run with `cargo nextest run --all-features`. The terminal
converter has headless rendering tests backed by Ghostty's virtual terminal
library, so full converter test and clippy runs require Zig 0.15.x on `PATH`.

[source,bash]
----
zig version
----

Install Zig with your system package manager or from
https://ziglang.org/download/[ziglang.org/download]. The Ghostty test dependency
fetches and builds its pinned Ghostty source during the Cargo build unless
`GHOSTTY_SOURCE_DIR` points at an existing Ghostty checkout.

On macOS 26 / Xcode 26.4 or newer, use a Zig install that includes the macOS
linker fix for C/libSystem-backed Zig build scripts.
